Executive Overview

What this system is, what the current analysis shows and how well it is supported, and what it must not be used for. Every figure on this page is read from the shared analysis run or derived from the dataset — none is written by hand.

Portfolio Analysis

Synthetic REIT holdings — city, asset class, value, yield and occupancy. No real properties, tenants or financial records.

Market Screener

Target market segments ranked by rental yield, rental growth, diversification benefit, demand strength and market risk.

Diversification (HHI)

Herfindahl-Hirschman Index measuring geographic and asset-class concentration in the synthetic portfolio.

Agent Output

Four Gemini agents interpret figures that were already computed deterministically: Data & Statistical Analyst, Market Screening Analyst, Portfolio Risk & Scenario Analyst, Investment Orchestrator. The input checks that gate the Orchestrator are performed in code, not by a model.

Data Centre

Dataset status, data quality pipeline, provenance and import controls. All data is synthetic — no live feed or external database connection.

Statistical Analysis

Consolidated analysis of the full observation-level dataset: distributions, correlation structure, regression fit, outlier-detection performance measured against known ground truth, and sample-size adequacy.

Investment Decision Report

Printable summary of the full analysis chain: portfolio, screening, diversification, scenario projections and agent commentary for the current run.
